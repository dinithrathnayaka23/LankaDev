# @lankadev/react

React provider, hooks, language switcher and transliteration input for Sinhala, Tamil and English apps.

> **Status:** pre-release scaffold (milestone M1). The public API lands in later milestones — see [docs/IMPLEMENTATION_PLAN.md](../../docs/IMPLEMENTATION_PLAN.md).

## Install

```sh
npm install @lankadev/react
```

Peer dependencies: `react` (^18.3.0 || ^19.0.0), `react-dom` (^18.3.0 || ^19.0.0).

## Usage

```ts
import { LankaProvider, useLanka } from "@lankadev/react";
```
