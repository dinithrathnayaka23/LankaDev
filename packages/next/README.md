# @lankadev/next

Next.js App Router helpers for Sinhala, Tamil and English apps: server locale detection and a client provider.

> **Status:** pre-release scaffold (milestone M1). The public API lands in later milestones — see [docs/IMPLEMENTATION_PLAN.md](../../docs/IMPLEMENTATION_PLAN.md).

## Install

```sh
npm install @lankadev/next
```

Peer dependencies: `next` (^15.0.0 || ^16.0.0), `react` (^18.3.0 || ^19.0.0), `react-dom` (^18.3.0 || ^19.0.0).

## Usage

```ts
// Server Components, route handlers, middleware:
import {} from "@lankadev/next/server";
// Client Components:
import {} from "@lankadev/next/client";
```
