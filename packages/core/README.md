# @lankadev/core

Locale configuration, fallback and LKR/number/date formatting for Sinhala, Tamil and English (Sri Lanka).

> **Status:** pre-release scaffold (milestone M1). The public API lands in later milestones — see [docs/IMPLEMENTATION_PLAN.md](../../docs/IMPLEMENTATION_PLAN.md).

## Install

```sh
npm install @lankadev/core
```

## Usage

```ts
import { createLankaConfig } from "@lankadev/core";
import { formatLKR } from "@lankadev/core/formatting";
```
