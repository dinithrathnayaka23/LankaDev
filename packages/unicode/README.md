# @lankadev/unicode

Script detection, normalization and grapheme-aware text helpers for Sinhala and Tamil Unicode text.

> **Status:** pre-release scaffold (milestone M1). The public API lands in later milestones — see [docs/IMPLEMENTATION_PLAN.md](../../docs/IMPLEMENTATION_PLAN.md).

## Install

```sh
npm install @lankadev/unicode
```

## Usage

```ts
import { detectScript } from "@lankadev/unicode";
```
