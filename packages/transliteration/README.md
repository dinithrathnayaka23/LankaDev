# @lankadev/transliteration

Deterministic Singlish-to-Sinhala and Tanglish-to-Tamil transliteration engines. Framework-agnostic.

> **Status:** pre-release scaffold (milestone M1). The public API lands in later milestones — see [docs/IMPLEMENTATION_PLAN.md](../../docs/IMPLEMENTATION_PLAN.md).

## Install

```sh
npm install @lankadev/transliteration
```

## Usage

```ts
import { transliterate } from "@lankadev/transliteration";
// or a single language only:
import {} from "@lankadev/transliteration/sinhala";
```
