# Language corpus: provenance

Test fixtures for Sinhala, Tamil and mixed-script text, used by `@lankadev/unicode` tests (and later
packages).

## Source

All entries are **synthetic and self-authored** for this project. They are common dictionary words,
place names, single letters and short made-up sentences. Nothing is copied from books, websites,
datasets, fonts or other software. The files are covered by the repository's MIT license
(ADR-0007).

## Files

| File           | Content                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------- |
| `sinhala.json` | Vowels, consonants, every vowel sign, al-lakuna, ZWJ conjuncts, split signs, sequence fixes |
| `tamil.json`   | Vowels, consonants, uyirmei, pulli, grantha letters, split vowel signs, digits              |
| `mixed.json`   | Script mixes, emoji, flags, digits, combining marks, CR LF, empty string                    |

## Entry shape

```jsonc
{
  "id": "si-yansaya", // unique across all files; prefix si-, ta- or mx-
  "input": "වාක්\u200dයය", // invisible characters are written as \uXXXX escapes
  "expected": {
    "script": "sinhala", // detectScript(input)
    "graphemes": ["වා", "ක්\u200d", "ය", "ය"], // extended grapheme clusters (UAX #29) of input
    "nfc": "…", // input.normalize("NFC")
    "normalized": "…", // optional: normalizeSinhalaText / normalizeTamilText result when it differs from nfc
  },
  "notes": "Why this case exists. needs-native-review marks cases that need a native speaker.",
  "reviewedBy": null, // GitHub handle of the native-speaker reviewer, once reviewed
}
```

`graphemes` were written by hand from the UAX #29 rules, then checked against `Intl.Segmenter` (ICU
78.3, Unicode 17, Node 24). They were not generated by the code under test.

## Review

No entry has been reviewed by a native speaker yet (`reviewedBy: null`). To review, check the
`input` renders and reads as described in `notes`, then set `reviewedBy` to your GitHub handle in a
pull request. Entries whose notes say `needs-native-review` matter most: they cover conjuncts
(yansaya, rakaransaya, repaya, touching letters) and grantha ligatures.
